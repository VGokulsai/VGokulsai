### The idea I keep running into

A source that searched and found nothing, and a source that was refused and never looked, both return zero. They mean opposite things.

Getting that wrong lets a tool tell someone their real problem is imaginary. It turns up in most of what I build, and it's harder than it sounds — DuckDuckGo refuses you with HTTP 202, a *success* code. Stack Exchange does it two different ways. Each one parses as "the parser is broken" if you check the body before the status.
